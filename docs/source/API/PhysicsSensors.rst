PhysicsSensors
--------------

**Runtime/Core/PhysicsSensors.cs**

Static measurements shared by the controller, telemetry, passenger overload protection and damage. These methods do not apply forces or decide whether an impact should cause damage. No global motion history is stored.

PhysicsSensors.MotionHistory
----------------------------

**Runtime/Core/PhysicsSensors.cs**

A mutable value-type history owned by one measurement point. Do not share it between different points or passengers. Sampling has no managed allocation.

.. _uvs-api-physicssensors--vehiclesensors:

VehicleSensors
--------------

**Runtime/Core/VehicleSensors.cs**

Read-only live measurements owned by :ref:`VehicleController.sensors <uvs-api-core--vehiclecontroller>`. The instance remains stable for the controller's lifetime. Motion and ground readings update once per physics tick, after all mechanics and before ``AfterPhysicsStep``; modules running during that tick see the previous completed sample. Reading properties does not cast rays or update history. Before the first sample, and after teleport, disabling/re-enabling or changing input source, ``HasSample`` is false and readings are cleared. Ground is sampled using the chassis origin, not the bottom of its collider. A missing hit reports zero height together with ``HasGroundBelow == false``.

An impact is copied immediately before the controller publishes ``Impacted``. It is independent of the most recent completed motion sample. ``LastImpact`` is the most recently published impact, not an accumulated or peak collision. ``HasImpact`` reports whether that snapshot had a contact; reset clears it. Sensors do not modify damage thresholds or passenger activation policy.

.. raw:: html

   <!-- example: VehicleSensorObservation.cs -->

.. code-block:: csharp

   using UnityEngine;
   using UltraVehicleSystem;

   namespace VehicleDocumentationExamples
   {
       public static class VehicleSensorObservation
       {
           public static void Observe(VehicleController vehicle)
           {
               var sensors = vehicle.sensors;
               if (!sensors.HasSample) return;
               Debug.Log($"G: {sensors.GForce:F2}, tilt: {sensors.TiltDegrees:F1}°");
               if (sensors.HasGroundBelow)
                   Debug.Log($"Ground clearance from chassis origin: {sensors.HeightAboveGround:F2} m");
           }
       }
   }

For stable retained per-tick data, continue to use immutable ``vehicle.Telemetry`` or ``AfterPhysicsStep``. A passenger measures acceleration at its own seat point using its own ``MotionHistory``; the chassis sensor is not substituted for point acceleration during vehicle rotation.
