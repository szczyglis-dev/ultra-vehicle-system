.. _uvs-inspectorreference-controller--directcontroller:

DirectController
----------------

Replaceable buffered input source with optional direct world-pose control. See :ref:`the direct-mode guide <uvs-input--direct-pose-control-for-ai-and-scripted-traffic>`.

**Source:** ``Runtime/Controller/Input/DirectController.cs``. Component / asset.

**Inherited settings:** :ref:`ExternalController <uvs-inspectorreference-controller--externalcontroller>`. These settings also appear on this type.

+-----------------------+---------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------------------+
| Setting               | Type          | Description                                                                                                                                                                         | Declared default and constraints |
+=======================+===============+=====================================================================================================================================================================================+==================================+
| ``automaticSteering`` | ``bool``      | Infer road-wheel steering from the path's heading change and travel. Turn off to use the normalized steering supplied through SetAxes or SetAnalogAxes, including while stationary. | ``true``                         |
+-----------------------+---------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------------------+
| ``directControl``     | ``bool``      | When selected as Input Source, move the chassis to requested poses instead of applying driving forces. Switching off resumes ordinary buffered input on the next physics tick.      | ``true``                         |
+-----------------------+---------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------------------+
| ``poseTarget``        | ``Transform`` | Optional independent world-pose target sampled each physics tick. Keep it outside the vehicle hierarchy. Leave empty to drive through SetPose.                                      | ``None / unassigned``            |
+-----------------------+---------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+----------------------------------+
